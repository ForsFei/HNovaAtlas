## 计算机为什么只用 0 和 1

CPU 里的晶体管本质上是**亿万个小开关**：通电是 1，断电是 0。让开关区分十种状态（0-9）？技术上极其脆弱；只区分"开/关"两种状态？稳定得可以塞进指甲盖里一百亿个。

这就是二进制的全部理由：**两个状态最可靠**。计算机里的一切——数字、文字、图片、这首歌——最终都是一长串 0 和 1。

## 数数的另一种方式

十进制是"逢十进一"：个位、十位、百位，每位有 10 种数字。

二进制是"逢二进一"，每一位只有 0 和 1：

| 二进制 | 含义 | 十进制 |
|--------|------|--------|
| `1` | 1 个 1 | 1 |
| `10` | 1 个 2 + 0 个 1 | 2 |
| `101` | 1 个 4 + 0 个 2 + 1 个 1 | 5 |
| `1101` | 8 + 4 + 0 + 1 | 13 |

每位的价值从右往左翻倍：1、2、4、8、16……把有 1 的位加起来就是十进制值。`1101` = 8 + 4 + 1 = 13，就这么简单。

你早就会这套方法——十进制就是这么用的，只是基数换成了 2。

## 位与字节：计量单位

- **位（bit）**：一个 0 或 1，信息的最小单位
- **字节（byte）**：8 个位一组，如 `01000001`

一个字节有 8 位，能表达 2⁸ = **256** 种不同的组合——刚好够给英文字母、数字、标点各编个号（ASCII 编码）：`01000001` 就代表字母 A。

更大的单位都是字节的倍数：

| 单位 | 大小 | 直观感受 |
|------|------|----------|
| 1 KB | 1024 字节 | 一段纯文本 |
| 1 MB | 1024 KB | 一张照片 |
| 1 GB | 1024 MB | 一部电影 |
| 1 TB | 1024 GB | 一整块硬盘 |

## 一切皆 0 和 1

文字、颜色、声音如何变成二进制？思路都一样：**编个号**。

- 字符 A → 编号 65 → `01000001`
- 红色 → RGB 三个数字 (255, 0, 0) → 每个数字再变二进制
- 声音 → 每秒采样几万次的音量数值 → 数值变二进制

图片放大看是一个个小色块（像素），每个像素就是三个数字；视频就是连续的图片；文字就是编号表。**数字化 = 把世界翻译成编号**。

<Callout type="tip" title="为什么程序员要懂二进制？">

日常确实用不到手算二进制，但三个场景离不开它：看懂报错里的十六进制地址、理解"32 位/64 位系统"的差别（一次能处理多少位）、以及为什么文件大小是 1024 的倍数而不是 1000。懂了 0 和 1，很多"计算机常识"瞬间通顺。

</Callout>

## 十六进制：二进制的简写

程序员经常写 `0xFF`、`#FF5733` 这种十六进制。它不是新东西，只是**二进制的缩写**：4 个二进制位（16 种组合）正好用 0-9 和 A-F 一个字符表示，`11111111` 写成 `FF` 省事得多。看到十六进制，心里把它展开成二进制就对了一半。
