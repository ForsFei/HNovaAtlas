## 从一个问题开始

手机、笔记本、游戏机、数据中心的服务器——外形千差万别，但它们跑的都是同一套思路。1945 年数学家冯·诺依曼把这套思路写成了一纸方案，直到今天，你手上的设备依然是"冯·诺依曼结构"。

理解它不需要任何硬件知识，用一间**餐厅厨房**就够了。

## 五个角色，一间厨房

想象一家餐厅接单做菜，需要哪些角色？

| 厨房角色 | 计算机部件 | 职责 |
|----------|-----------|------|
| 菜谱 | **存储器**（内存） | 记着"要做什么、怎么做" |
| 主厨 | **运算器**（CPU 的一部分） | 真正动刀动锅干活的 |
| 厨师长 | **控制器**（CPU 的另一部分） | 决定先做哪道菜、指挥全局 |
| 前厅点单 | **输入设备** | 键盘、鼠标、触摸屏，把请求送进厨房 |
| 出餐口 | **输出设备** | 屏幕、音箱、打印机，把结果递出去 |

```mermaid caption="冯·诺依曼结构：数据怎么流动"
flowchart LR
  I[输入设备] --> M[存储器]
  M --> CPU[运算器 + 控制器]
  CPU --> M
  CPU --> O[输出设备]
```

关键设计只有一条：**程序和数据都放在存储器里**。菜谱不是刻在主厨脑子里的，而是写好放在厨房架子上——想换菜，换一张纸就行，不用重新造一个主厨。

<Callout type="info" title="这就是为什么计算机这么能干">

同一台计算机，装不同的程序，就能剪视频、写文档、打游戏。硬件不变，"菜谱"（软件）随便换——"存储程序"这个 1945 年的点子，是今天整个软件产业的根基。

</Callout>

## CPU：运算器 + 控制器打包在一起

厨房里，主厨和厨师长通常由同一个人兼任——计算机里也一样。**CPU（中央处理器）**同时包含运算器和控制器，是整台机器的指挥中心。它有多小多快，下一篇细讲。

## 存储器不止一种

厨房里放东西的地方也有讲究：手边的小料台、后厨的货架、外面的仓库。计算机的存储同样分层——内存断电即忘但飞快，硬盘记住一切但慢得多。这是第四篇的主题。

## 一条指令的一生

你在键盘上敲下一个字母，到屏幕上显示出来，中间发生了什么？

1. 输入设备把按键交给 CPU
2. CPU 从存储器取出对应的指令
3. 运算器执行，结果写回存储器
4. 输出设备把结果显示到屏幕

整个过程每秒发生几十亿次——这就是"计算机很快"的全部秘密：**简单的事，快得吓人**。
