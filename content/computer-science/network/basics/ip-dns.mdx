## 门牌号：IP 地址

上一篇说过，每个包裹都要写收件地址。互联网上的地址就是 **IP 地址**，例如 `142.250.196.110`。规则很朴素：

- **IPv4**：四段数字，每段 0-255，如 `192.168.1.100`——共约 43 亿个组合
- **IPv6**：地址不够用了，扩成更长的编号如 `240e:5617::8888`——多到"地球每粒沙子都能分一个"

IP 地址分两类角色：

| | 公网 IP | 内网 IP |
|---|---|---|
| 谁在用 | 网站服务器、你家宽带的出口 | 家里的电脑、手机、电视 |
| 例子 | `142.250.196.110` | `192.168.1.100` |
| 特点 | 全球唯一，可被直接找到 | 只在小区（局域网）内有效 |

内网地址在千家万户重复出现没关系——就像小区内部楼栋编号，出了小区靠大门（路由器）统一对外。`192.168.` 开头的都是内网号，你家和邻居家可以完全一样。

<Callout type="tip" title="查一查你自己的地址">

命令行输入 `ipconfig`（Windows）：看到"IPv4 地址"是你在这张网里的内网门牌；搜索引擎搜"我的 IP"看到的是你家对外的公网出口。两个不同的号，正好对应上表。

</Callout>

## 域名：给门牌起个好记的名字

记不住 `142.250.196.110`，但记得住 `google.com`。**域名**就是 IP 的好记别名——而把域名翻译回 IP 的系统叫 **DNS**（域名系统），互联网的**电话簿**。

为什么必须有电话簿？因为你跟快递员只能说门牌号（计算机只认 IP），但你自己只需要记住名字。

层层缓存的巧思：绝大多数查询在第一两步就命中了，真正打通全链路的只有第一次。

<Callout type="warning" title="DNS 出问题是什么体验？">

"网页打不开，但微信还在线"——多半是 DNS 查不到 IP（聊天软件的 DNS 早缓存好了）。换个 DNS 服务器（如 `223.5.5.5`）常能立竿见影。知道 DNS 的存在，你就能看懂这类故障。

</Callout>

## 端口：一栋楼里的房间号

IP 定位到了电脑，但电脑上同时跑着浏览器、游戏、微信——数据交给谁？**端口（port）**就是楼里的房间号，0-65535 的编号：

| 端口 | 常驻服务 |
|------|----------|
| 80 | HTTP 网页 |
| 443 | HTTPS 网页 |
| 22 | SSH 远程登录 |

完整的"门牌"其实是 `IP:端口`，比如 `93.184.216.34:443`。快递员按 IP 找到楼，再按端口敲对房间门。

## 动手试一试

1. `ping baidu.com` 观察输出的 IP；再用浏览器访问同一个 IP，体会"域名只是 IP 的别名"。
2. 命令行 `nslookup baidu.com`，亲手做一次 DNS 查询，看答案从哪台服务器回来。
3. 试试 `nslookup taobao.com` 多次执行，观察 IP 是否变化——大网站用多个地址分摊流量。
