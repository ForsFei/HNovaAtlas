## 这一批解决什么问题

前篇由二值区域提取轮廓，再算面积、凸包和旋转框。这一篇换一个入口：直接观察灰度变化，找可能的边，再判断它像直线还是圆。常见任务包括定位工件侧边、寻找圆孔候选、检查条带边界，以及为后续局部测量准备搜索范围。

不要把这条链写成“Canny一运行，尺寸就出来了”。至少分清四层责任：

| 层次 | 输入 → 输出 | 还不能证明什么 |
| --- | --- | --- |
| 边缘提取 | 灰度 → 边缘像素 | 像素属于哪个工件、内边还是外边 |
| 候选检测 | 边缘/灰度 → 线段或圆候选 | 候选唯一、尺寸准确、目标合格 |
| 关联点拟合 | 同一几何边的样本 → 参数与残差 | 关联正确、无异常点、实际毫米精度 |
| 测量与判定 | 几何、标定、工艺条件 → 尺寸及状态 | 必须另外验证，不能由检测分数代替 |

本批交付前三层的独立教学示例，不自动建立Hough候选与拟合点的关联。C#实践中检测图像与已知点集明确分开，下一批再连接受约束的局部测量。

## 1. 灰度、梯度与边缘不是同一个量

灰度描述亮暗，梯度描述邻域内亮暗如何变化。亮平台内部很亮但梯度接近零；从暗背景进入亮平台时才出现较强变化。理想阶跃经过镜头、离焦、曝光、采样后通常成为一段过渡，不会天然落在精确整数边界。

用Sobel等差分获得Gx、Gy时，梯度方向沿变化最快的方向，通常垂直于边的切线。图像坐标仍是x向右、y向下，不直接等同机械坐标。梯度幅值也不是原图灰度，Canny阈值不能按“8位图最大255”机械理解。

边缘可能来自目标外边、内孔、纹理、反光、阴影、污点。把所有边缘都交拟合，不等于更多数据带来更准确结果：一条亮条会贡献上下两条边，一枚垫片会贡献内外两个圆。

## 2. Canny做了什么

本例显式先GaussianBlur，再Canny。概念链是：抑制噪声 → 求梯度 → 非极大值抑制使边变细 → 双阈值与连接追踪。高阈值确认强响应；介于两阈值之间的弱响应需要与强边连接才可能保留。低阈值不是“另一套独立二值分割”。[OpenCV Canny教程](https://docs.opencv.org/4.13.0/da/d22/tutorial_py_canny.html)

几个容易混淆的地方：

- GaussianBlur是本例明确的前处理，不声称每次Canny调用都会自动执行这里的5×5高斯配方。
- Threshold按像素亮暗分区；Canny按局部变化及连接关系找边，不能互换阈值含义。
- L2Gradient=true使用欧氏幅值；false采用另一种幅值计算。换模式后不能假定同一阈值保留同样的边。
- apertureSize控制Sobel孔径，本例限定3、5、7。核变大不意味着精度必然提高。
- 输出为边缘图，CountNonZero统计的是边缘像素数，不是轮廓长度、圆周真值或工件数量。

调参先确认光照、对焦和曝光，再看原图与滤波图，最后检查边缘是否保留需要的物理边。不要先用强平滑消除所有细节，再靠降低阈值找回已被抹去的缺陷。

## 3. Hough直线：从投票找候选

一条直线可以写成x·cosθ+y·sinθ=ρ。一个边缘点对应参数空间的一组可能直线；多个点支持同一参数时形成峰值。ρ、θ的离散分辨率、投票门槛都会影响候选。[OpenCV Hough直线教程](https://docs.opencv.org/4.13.0/d9/db0/tutorial_hough_lines.html)

常用接口的输出不是一回事：

| 接口 | 主要输出 | 适合先理解的用途 |
| --- | --- | --- |
| HoughLines | ρ、θ形式的无限直线 | 理解全局投票与法线参数 |
| HoughLinesP | 两个整数端点的线段候选 | 寻找较长直边、显示候选范围 |
| FitLine | 关联点集的方向与线上一点 | 点已归属同一边之后估计几何 |

HoughLinesP中，rho是像素距离分辨率，theta是弧度分辨率，threshold是投票门槛，minLineLength是最短线段，maxLineGap允许连接的最大间断。本例分别为1、π/180、20、30、3，全部只是固定夹具配方。

提高maxLineGap会连接断边，也可能跨过缺口或两个独立目标。两条近似平行边都被检测到不算算法错误。线段顺序、端点先后、数量不应当作稳定身份，也不默认第一条就是基准边。检测到的有限线段端点也不是无限直线的“天然测量端点”。

## 4. Hough圆：先找大致位置，不直接报尺寸

本例用HoughModes.Gradient，输入经过平滑的8位单通道灰度，不是前面Canny的0/255边缘图。该方法内部利用梯度找中心和半径；不要把输入改成边缘图却仍按灰度梯度配方理解结果。[OpenCV Hough圆教程](https://docs.opencv.org/4.13.0/d4/d70/tutorial_hough_circle.html)

参数要分别理解：

| 参数 | Gradient模式中的责任 | 常见误解 |
| --- | --- | --- |
| dp | 累加器分辨率与图像分辨率的比例关系 | 越小就一定获得亚像素测量 |
| minDist | 候选圆心的最小间距 | 工件实际最小间距或内外圈区分保证 |
| param1 | 内部边缘检测的高阈值 | 原图二值阈值 |
| param2 | 该模式的圆心累加器门槛 | 合格概率、圆拟合RMS |
| minRadius/maxRadius | 搜索半径范围，单位像素 | 直径或毫米范围 |

不同Hough模式的参数语义不能直接套用。本例仅验证Gradient；没有验证GradientAlt，也不把网上另一模式的param2配方复制进来。

128×128夹具中画中心(64,64)、半径24的亮圆盘。本机固定版本实际返回一个中心(62.5,62.5)、半径约22.7px的候选，断言容差3px。这个偏差被保留下来：测试通过只表示这张合成图找到了附近候选，不是半径精度3px的产品承诺。返回float也不意味着实际具有相应小数位精度。

## 5. FitLine：不要只会写y=kx+b

斜截式遇到竖线会出问题，更通用的参数形式是P(t)=P0+t·v。v=(vx,vy)为单位方向，P0=(x0,y0)为线上一点。v与−v表示同一条无向直线，P0也不是唯一；不能用向量正负判断运动方向。

对样本Pi，垂直残差可以写为 `(Pi.x-x0)*vy - (Pi.y-y0)*vx`；平方平均再开方得到像素RMS。把点投影到v后，最小和最大投影可以给出“这些样本支持的显示范围”，但不证明真实物体的物理端点就在那里。

本批使用DistanceTypes.L2。OpenCV还提供Huber等距离损失选择，但换损失不等于自动完成异常点识别、目标关联或RANSAC。reps、aeps是算法停止精度相关参数，不是样本内点门槛、置信度或实际测量精度。[OpenCV形状接口](https://docs.opencv.org/4.13.0/d3/dc0/group__imgproc__shape.html)

已知同一侧边的样本才适合一起拟合。若把亮条上下边合并，拟合可能得到中线，RMS也可能看起来不大，但它并不是任何一侧的边界；若工艺需要中线，应先明确两边的定义和配对方法。

## 6. 圆检测、外接圆与圆拟合的区别

HoughCircles从图像中搜索圆候选；MinEnclosingCircle寻找包含给定点集的最小圆；圆拟合则希望某个圆尽量贴近一组关联边缘点。三者的输入、优化目标和异常点行为不同。只在理想圆点上数值接近，不代表可以互相替代。

本例的FitCircle是自写教学方法名，不是OpenCvSharp提供的Cv2.FitCircle。实现的是代数最小二乘：先将点中心化并按RMS尺度归一化为u、v，再求解：

```text
2*u*a + 2*v*b + c ≈ u*u + v*v
归一化圆心 = (a, b)
归一化半径 = sqrt(c + a*a + b*b)
最后还原原坐标与尺度
```

用Cv2.Solve和SVD求超定线性问题，不显式求逆或构造正规方程。SVD能返回最小二乘/伪解，但不会证明几何条件良好，更不保证该圆有物理意义。[OpenCV Solve文档](https://docs.opencv.org/4.13.0/d2/de8/group__core__array.html)

代数误差并非点到圆的径向几何距离。求解之后另算 `sqrt(mean((点到圆心距离−半径)^2))` 作为径向RMS，它是诊断值，不能把求解方法写成“已最小化径向RMS”。进一步的几何迭代拟合、异常点剔除及不确定度分析需要单独实现与验证。

## 7. 点数够不等于圆可靠

数学上三个不共线点确定圆，实际带噪测量却不能因为有三个点就放心。本例策略要求至少6点，最多1024点，检查有限坐标、点集尺度和近共线性；这些是教学保护范围，不是工业通用标准。

短圆弧尤其危险：很短的一段弧看起来近似直线，微小点位变化可能让圆心和半径大幅漂移，而拟合残差仍很小。点数很多也可能全挤在这一小段上。示例只用协方差展开度门槛拒绝明显近共线样本，没有完成角度覆盖、独立检查点或协方差不确定度评估。

还应特别警惕：

- 内外边混入同一组，得到两者之间的圆。
- 透视下圆变椭圆，仍硬套圆模型；“找得到圆”不能代替成像几何检查。
- 镜头畸变、反光、曝光和边缘极性带来系统偏差，RMS不一定揭示。
- 同一轮廓重复采样、局部采样密集，使权重偏向某一段。
- 一个远离圆的异常点改变代数拟合结果，本例专门保留失败性质检查。

## 8. 调试顺序与面试回答

推荐顺序是：固定原图和ROI → 确认灰度/噪声 → 检查Canny是否包含需要的边 → 看候选数量与位置 → 明确样本归属和极性 → 拟合并看残差、覆盖范围及失败样本 → 最后讨论标定、公差和设备联动。不要只盯着一张漂亮的叠加图。

面试问“如何测圆孔直径”，可以回答：先明确成像和平面/畸变条件，在预计孔位附近找圆候选或局部边缘，选择同一孔壁且极性一致的样本，检查覆盖和异常点，再拟合圆并保留像素残差；有独立标定与重复性证据才转实际尺寸，缺失或多候选不能随意取第一项。Hough适合候选定位，未必是最终测量方法。
