## 从找候选，走到一个受约束的测量任务

前一批讲Canny、Hough和直线/圆拟合，但没有把任意候选直接当成尺寸。这一批先完成一个更小、更可解释的任务：在预先给定的矩形ROI中，沿X或Y扫描一条亮条/暗槽，报告两侧边之间的像素距离。

适用前提是两侧边大致垂直于扫描轴，ROI跨过完整条带并包含两侧背景，平均方向上没有必须独立区分的多件目标。算法不会自动证明这些前提成立，示例也没有接上一批Hough候选自动选择ROI。

本例是使用OpenCV基础运算搭建的一维教学测量器，不是调用一个现成的OpenCvSharp“卡尺测量对象”，也不宣称复现HALCON的MeasurePos/MeasurePairs。后者有自己的滤波、取样、插值与选择语义，本例参数不能直接照搬。

## 1. ROI的两个方向，分别承担什么责任

以沿X扫描为例：每个x位置，将ROI中所有行的灰度取平均，得到一条随x变化的一维轮廓。它不是二值轮廓点列，也不是FindContours的输出。

```text
沿X：ROI为H×W → 对H行求平均 → 长度W的灰度序列
沿Y：ROI为H×W → 对W列求平均 → 长度H的灰度序列
```

扫描方向负责穿过两条边；垂直方向负责平均。增加平均范围能降低某些随机噪声的影响，但会混入其他物体、倾斜边、局部缺料或光照变化，不是越宽越好。相同位置的系统偏差不会因为平均行数增加而自动消失。

OpenCV的Reduce可以将二维矩阵压缩成单行或单列；本例选择Avg，并输出64位浮点数以保留小数平均值。[OpenCV Reduce说明](https://docs.opencv.org/4.13.0/d2/de8/group__core__array.html)

本例ROI必须完全包含在输入图中。不能悄悄把越界窗口裁短：窗口的采样范围、中心线、预计边缘位置和保护距离都会随之改变。窗口越界是参数错误，不是正常的“未找到”。

## 2. 灰度轮廓、平滑轮廓、差分轮廓

三个量应分别观察：

| 数据 | 示例中表示什么 | 不是什么 |
| --- | --- | --- |
| MeanProfile | 每个扫描位置的平均灰度 | 对象数量、二值面积 |
| SmoothedProfile | 显式高斯平滑后的平均灰度 | 已识别的工件边界 |
| 相邻差分 | p[i+1]−p[i] | 原图灰度、Canny梯度或拟合残差 |

高斯平滑抑制高频变化，也会展宽边缘响应，使很近的两条边互相影响。本例核长度固定5、sigma默认1、边界Reflect101，沿扫描轴平滑，不在平均方向再叠加二维模糊。[OpenCV GaussianBlur参考](https://docs.opencv.org/4.13.0/d4/d86/group__imgproc__filter.html)

这里的差分是本例C#直接计算的一阶相邻差，不是Cv2.Sobel，更不是Canny输出。DifferenceThreshold=20表示平滑后相邻样本差的绝对值至少20才保留；换相机位深、曝光、平均范围、核或sigma后，都应重新评估。不要把Canny的50/150或HALCON的幅值阈值直接复制过来。

## 3. 为什么差分位置写成i+0.5

采用像素中心为整数索引的约定时，p[i]与p[i+1]的差位于两者之间，所以记在i+0.5。若亮条覆盖整数x=40..71，共32列，则理想阶跃边界位于39.5和71.5，两者之差为32，而不是用71−40得到31。

这说明必须先定义测量对象：是像素中心间距、栅格占用宽度，还是经过成像与插值估计的边界间距？它们不能混为一谈。本例只在固定理想图中用对称灰度变化验证这个约定。

返回小数坐标不等于已获得实际亚像素精度。半像素来自差分位置约定，后续更多小数来自加权计算；实际精度仍取决于光学、噪声、算法偏差和验证方法。

## 4. 一条边可能产生多个差分样本

理想阶跃平滑后会展开为数个同号差分。如果把每个超阈值样本都当作一条边，一个真实边界可能被重复计数。

本例将“相邻、同号、绝对值不小于门槛”的差分归为一组。每组保留起止差分索引、带符号峰值，并按差分绝对值加权定位：

```text
position = sum((i+0.5) * abs(d[i])) / sum(abs(d[i]))
```

权重和为正由正阈值保证。不同符号不能合并，阈值以下的间隔会断开组；不自动跨过间断，也没有非极大值抑制、峰形拟合或异常点剔除。最多64组，过量显式报错，不截掉多余边后再假装只剩一对。

这个加权位置是本例的工程选择，不是普遍最优的边缘位置估计。阈值截断、不对称光照、相邻边干扰都可能改变它。教学夹具上的对称性不能推广成真实工件的精度保证。

## 5. 极性永远相对于扫描方向

按扫描顺序看灰度变化，暗→亮为正，亮→暗为负。因此两侧背景相似且完整跨过目标时：

| 任务 | 第一条边 | 第二条边 |
| --- | --- | --- |
| 亮条 | 正 | 负 |
| 暗槽 | 负 | 正 |

反向扫描会反转样本顺序，同一物理边的差分符号也翻转。完整亮条反向后的第一条边仍是正边，但那是原来的另一侧边，不能误以为物理左右身份没有变化。

本例Reverse=true在投影和平滑之后反转两条序列，再计算差分。沿扫描方向的位置s转回正轴局部坐标为N−1−s；不能只在显示时反转箭头，却继续沿用原来的极性和坐标。

## 6. 配对与“唯一测量”分开处理

先保留所有边组，再检查相邻两组是否符合亮条的正/负或暗槽的负/正，得到候选Pairs。不会跨越中间边直接把最外侧两条拼成一个尺寸，也不按“最强”“最宽”偷偷挑一组。

本例发布宽度的条件更严格：整条轮廓恰好两组边、恰好一组符合配方的配对、没有靠近采样端点的响应。仅有一组合适配对、但还多一条未配对边，也返回歧义，不发布单一尺寸。

| Outcome | 含义 | WidthPixels |
| --- | --- | --- |
| BoundaryResponse | 任一边组触及端部保护范围，优先于其他状态 | null |
| NoEdges | 没有超阈值边组 | null |
| NoPair | 有边但没有符合极性的相邻对 | null |
| Ambiguous | 有候选对，但还有额外边或多对 | null |
| WidthMeasured | 恰好两边/一对且无边界响应 | 两位置之差，正的像素值 |

边与候选配对在失败状态仍保留，便于解释原因。WidthMeasured只说明这套投影和配对规则得到一个像素距离，不是产品OK、实际尺寸合格或设备执行许可。

## 7. 为什么增加端部保护

有限ROI需要滤波边界外推。本例显式采用Reflect101，但镜像外推并不是实际观测到的背景。若响应过于靠近轮廓端点，它可能受截断或外推影响。

实现固定Guard=3：任何组的起始差分索引小于3，或结束索引不小于N−1−3，都返回BoundaryResponse。它比5点平滑/相邻差分的最基本支持范围更保守一点，是教学策略，不是普遍的测量标准。

这个保护只能拒绝已检测到的近端响应。若另一侧边已经完全在ROI外，通常只剩一条边，返回NoPair；若被截断的响应没有过门槛，也不能凭“无边界响应”证明目标完整。不能用保护范围替代正确的窗口选择和工件定位。

## 8. 局部坐标、输入图坐标与毫米

沿X时，报告点的x=ROI.X+局部位置，y=ROI.Y+(Height−1)/2；沿Y时对调。这个点位于平均窗口的代表中心线，只为描述投影位置，不是算法逐行观察到的真实边缘点。

默认窗口(16,16,96,32)得到扫描位置23.5与55.5，转回输入图为(39.5,31.5)、(71.5,31.5)。反向扫描时端点顺序互换，宽度仍为32。

若传入Mat本身就是父图ROI，本方法只知道这个输入Mat的坐标；不会猜它在原相机图中的裁剪偏移。显示/标定之前，调用者必须明确转换到哪一个坐标域。

宽度是沿X或Y扫描轴的距离，不一定是两条倾斜边之间的法向最短距离；投影平均还可能展宽斜边。因此本批没有自动修正倾斜角，也不将像素距离直接乘一个经验比例输出毫米。[平面映射与误差背景](/knowledge/industrial/host-computer/vision/image-coordinates-planar-calibration-and-errors/)

## 9. 一个故意保留的局限：平均会掩盖缺料

测试构造32行窗口，只有上16行有亮条，下16行仍为暗背景。亮条区域平均灰度为(220×16+20×16)/32=120，仍高于背景20。算法照样可以找到两边并测出20px的投影宽度。

这项测试通过，不是在夸检测能力，而是在证明它的适用边界：平均灰度轮廓测量不能证明每一行都有材料，更不能替代缺口、断裂或完整性检查。若工艺要求逐行一致性，应分别采样多个窄带或检查区域/边缘覆盖，并制定独立的失败标准。

类似地，两个不同物体、反光造成的边、内外壁混合，都可能形成看似合理的一对响应。本例的严格边数规则降低某些歧义，但不证明工件身份。

## 10. 调试与面试中的表达

先固定原图、窗口、扫描方向与预计极性，再依次看MeanProfile、SmoothedProfile、边组和候选对。NoEdges先检查对比度/方向/门槛；NoPair检查是否只扫到一侧或极性相反；Ambiguous检查是否混入孔洞、纹理、多件；BoundaryResponse先重新评估窗口，不能直接删去边界响应继续测量。

面试问“如何测条带宽度”，可以回答：在定位后受约束ROI内沿边界法向取样，定义极性、滤波与边位置，检查缺边/多边/采样边界，保留像素结果及诊断；再依据标定、误差和重复性验证转换实际尺寸。当前教学实现先限定轴对齐投影，不声称已经实现完整旋转卡尺、亚像素精度或工艺验收。
