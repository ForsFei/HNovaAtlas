## await 等待的是什么

`Task` 表示一项异步操作。`await` 在操作未完成时让异步方法暂停，并在操作完成后继续执行。它不是要求当前线程一直阻塞等待。

## 一个 I/O 示例

```csharp filename="PageReader.cs" {10}
using System.Net.Http;
using System.Threading;
using System.Threading.Tasks;

public static async Task<string> ReadPageAsync(
    HttpClient client,
    string url,
    CancellationToken cancellationToken)
{
    return await client.GetStringAsync(url, cancellationToken);
}
```

示例通过调用方传入 `HttpClient` 与取消令牌，等待网络读取完成，再返回结果。

## 异步不等于自动创建线程

I/O 操作和 CPU 密集计算要区别处理。给方法加上 `async`，不会自动把其中的所有工作转移到后台线程。
