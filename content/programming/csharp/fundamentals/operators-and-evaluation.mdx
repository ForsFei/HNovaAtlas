## 三个问题不要混成一个

读 `A() + B() * C()` 时，分别问：

1. **优先级**：先把它分成 `A() + (B() * C())`，乘法结果进入加法。
2. **结合性**：同一优先级如何分组，如 `10 - 3 - 2` 是 `(10 - 3) - 2`。
3. **求值顺序**：为了取得操作数，`A()`、`B()`、`C()` 依次从左到右调用；不是先调用 `B()`、`C()` 再调用 `A()`。

下面用可观察的日志验证第三点：

```csharp
var calls = new List<string>();
int A() { calls.Add("A"); return 2; }
int B() { calls.Add("B"); return 3; }
int C() { calls.Add("C"); return 4; }

Console.WriteLine(A() + B() * C()); // 14
Console.WriteLine(string.Join(",", calls)); // A,B,C
```

括号首先表达分组，不应把它当成“让所有内部调用都先于外部左操作数执行”的开关。比如 `A() + (B() * C())` 仍先求 `A()`。如果业务正确性依赖多个方法的副作用顺序，最好拆成独立语句，而不是写成一道运算符谜题。

## 结合性不是运行方向

多数二元运算符左结合；`13 / 5 / 2` 等价于 `(13 / 5) / 2`。赋值、`??` 和条件运算符 `?:` 等右结合：`a ?? b ?? c` 分组成 `a ?? (b ?? c)`。这说的是**语法分组**，不是“先执行最右侧表达式”。操作数仍按语言规定的顺序求值，但部分运算符可能跳过右侧。

```csharp
Console.WriteLine(2 + 3 * 4);   // 14
Console.WriteLine((2 + 3) * 4); // 20
Console.WriteLine(13 / 5 / 2);  // 1：先 13 / 5 得 2，再 2 / 2
```

不用背完整优先级表来写生产代码。混合算术、比较、逻辑与空值运算时，用少量括号表达意图；如果仍难一眼读懂，拆局部变量通常更好。

## 短路决定右侧会不会执行

对 `bool`，`&&` 在左侧为 `false` 时跳过右侧；`||` 在左侧为 `true` 时跳过右侧。`&`、`|` 用在 `bool` 上也能算逻辑结果，但会计算两侧。选择它们不能只看最后的 `true`/`false`，还要看右侧是否有调用、异常或状态修改。

```csharp
int calls = 0;
bool Check() { calls++; return true; }
bool gate = false;

_ = gate && Check(); // calls 仍为 0
_ = gate & Check();  // calls 变为 1
```

`condition ? ifTrue : ifFalse` 只求值被选中的分支。`left ?? Fallback()` 仅在 `left` 为 `null` 时调用后备方法；`left ??= Create()` 仅在左侧为 `null` 时赋值并计算右侧。`?.` / `?[]` 遇到 `null` 会跳过相应的成员/元素访问及其参数，但若接收者非空，访问本身抛出的异常不会被“吞掉”。这些运算符都是有条件求值，而普通方法调用不会自动短路。

可空基础语义见[类型与空值](/knowledge/programming/csharp/fundamentals/types-and-nullability/)；这里关注的是**是否执行右侧**，不是把 `??` 和 `?.` 当成避免一切异常的工具。

## 数值类型会改变结果

`7 / 2` 的两个操作数是整数，结果为 `3`，向零截断；`(double)7 / 2` 得到 `3.5`。`(double)(7 / 2)` 却仍是 `3`，因为转换发生在整数除法之后。若整数运算可能溢出，可在关键表达式使用 `checked`，但它不代替外部输入验证；详见[类型选择、转换与装箱](/knowledge/programming/csharp/fundamentals/data-types-and-conversions/)。

后置 `x++` 先产生旧值再更新变量，前置 `++x` 先更新再产生新值。不要在同一条复杂表达式里多次修改和读取同一个变量，即使能预测结果，可读性和维护性仍很差。

## 完整可运行例子

将以下整段放入 .NET 10 控制台项目的 `Program.cs`，先预测每行输出，再运行：

```csharp filename="Program.cs"
var order = new List<string>();
int First() { order.Add("first"); return 2; }
int Second() { order.Add("second"); return 3; }
int Third() { order.Add("third"); return 4; }

Console.WriteLine(First() + Second() * Third()); // 14
Console.WriteLine(string.Join(",", order)); // first,second,third

int checks = 0;
bool Check() { checks++; return true; }
bool gate = false;
_ = gate && Check();
Console.WriteLine(checks); // 0
_ = gate & Check();
Console.WriteLine(checks); // 1

string? cached = null;
int builds = 0;
string Create() { builds++; return "ready"; }
cached ??= Create();
cached ??= Create();
Console.WriteLine($"{cached}, builds={builds}"); // ready, builds=1

string? absent = null;
int arguments = 0;
string Argument() { arguments++; return "x"; }
bool? contains = absent?.Contains(Argument());
Console.WriteLine($"{contains is null}, arguments={arguments}"); // True, arguments=0

Console.WriteLine($"{7 / 2}, {(double)7 / 2}, {(double)(7 / 2)}"); // 3, 3.5, 3
int n = 1;
int oldValue = n++;
int newValue = ++n;
Console.WriteLine($"{oldValue}, {newValue}, {n}"); // 1, 3, 3
```

## 自测与面试追问

1. `F() + G() * H()` 中，方法调用顺序与算术操作顺序各是什么？
2. `false & SideEffect()` 与 `false && SideEffect()` 的结果可能一样，行为为什么可能不同？
3. `a ?? b ?? c` 的结合方向是什么？`a` 非空时，`b`、`c` 会执行吗？
4. `(double)(7 / 2)` 为什么不是 `3.5`？
