## 一组数据放在一起

记录全班同学的分数，总不能写 40 个变量。**列表**（list）把多个值按顺序装进一个变量，用方括号包住、逗号分隔：

```python filename="list-basic.py"
scores = [92, 85, 77, 100, 63]
names = ["小明", "小红", "小刚"]
mixed = [1, "two", 3.0, True]     # 类型可以混搭（不推荐滥用）
empty = []                        # 空列表
```

## 按下标取用

和字符串一样，下标从 0 开始，也支持负下标和切片：

```python filename="list-index.py"
scores = [92, 85, 77, 100, 63]
print(scores[0])     # 92，第一个
print(scores[-1])    # 63，最后一个
print(len(scores))   # 5，长度
print(scores[1:3])   # [85, 77]，切片（含头不含尾）
print(100 in scores) # True，判断是否存在
```

## 列表是"可变"的

字符串改不了单个字符，但列表可以随时增删改：

```python filename="list-mutable.py"
todo = ["写作业", "洗碗"]
todo[0] = "写数学作业"        # 修改
todo.append("跑步")           # 末尾添加
todo.insert(1, "看书")        # 插到指定位置
todo.remove("洗碗")           # 按值删除
last = todo.pop()             # 弹出末尾元素
print(todo)                   # ['写数学作业', '看书']
```

常用方法速查：

| 方法 | 作用 |
|------|------|
| `append(x)` | 末尾添加 x |
| `insert(i, x)` | 在下标 i 处插入 x |
| `remove(x)` | 删除第一个值为 x 的元素 |
| `pop()` | 取出并删除末尾元素 |
| `sort()` | 原地从小到大排序 |
| `reverse()` | 原地反转 |

## 遍历列表

for 和列表是天生一对：

```python filename="for-list.py"
scores = [92, 85, 77]

for s in scores:
    print(s)

# 需要下标时用 enumerate，同时拿到序号和值
for index, s in enumerate(scores):
    print(f"第 {index + 1} 个：{s}")
```

## 一个实用组合：统计

```python filename="stats.py"
scores = [92, 85, 77, 100, 63]
print(sum(scores))   # 417  求和
print(max(scores))   # 100  最大
print(min(scores))   # 63   最小
print(len(scores))   # 5    个数
print(sum(scores) / len(scores))   # 83.4 平均分
```

<Callout type="info" title="排序的两种方式">

`scores.sort()` 直接修改原列表，返回 None；`sorted(scores)` 不动原列表，返回排好序的新列表。想保留原始顺序就用 `sorted()`。降序都加参数 `reverse=True`。

</Callout>
