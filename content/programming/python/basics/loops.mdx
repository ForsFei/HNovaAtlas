## 为什么需要循环

打印三句"早安"，复制粘贴三行就行；打印一千句呢？**循环**让计算机替你重复，你只描述"重复什么"和"重复多少次"。

## for + range：重复固定次数

```python filename="for-range.py"
for i in range(3):
    print("早安")

# 输出三行：早安
```

`range(3)` 生成 0、1、2 三个数，变量 `i` 依次拿到它们，循环体执行三次。想看到进度，可以直接打印 `i`：

```python filename="for-i.py"
for i in range(3):
    print(f"第 {i} 遍")
# 第 0 遍
# 第 1 遍
# 第 2 遍
```

`range` 的三种用法：

| 写法 | 含义 |
|------|------|
| `range(5)` | 0 到 4 |
| `range(1, 6)` | 1 到 5（含头不含尾） |
| `range(0, 10, 2)` | 0, 2, 4, 6, 8（步长 2） |

## for 遍历字符串

for 能逐个取出字符串（以及后面的列表、字典）里的元素：

```python filename="for-string.py"
for ch in "abc":
    print(ch)
# a
# b
# c
```

## while：满足条件就一直做

不知道要重复多少次、只知道"什么情况下继续"时，用 `while`：

```python filename="while.py"
count = 3
while count > 0:
    print(count)
    count -= 1      # 别忘了更新条件变量！
print("发射！")
```

<Callout type="danger" title="小心死循环">

如果 while 的条件永远为 True，程序就永远停不下来（死循环）。写 while 时先问自己：循环体里有什么代码会让条件最终变 False？上面例子里就是 `count -= 1`。万一卡死，按 `Ctrl + C` 强行停止。

</Callout>

## break 与 continue

- `break`：立刻跳出整个循环
- `continue`：跳过本轮剩余部分，直接进入下一轮

```python filename="break-continue.py"
for i in range(1, 6):
    if i == 4:
        break          # 到 4 就整体结束
    if i == 2:
        continue       # 2 这一轮跳过
    print(i)
# 输出：1  3
```

## 循环里可以做选择

循环和条件组合才是真正干活的样子——遍历并筛选：

```python filename="filter.py"
total = 0
for n in range(1, 101):
    if n % 2 == 0:       # 只要偶数
        total += n
print(total)             # 2550，1 到 100 的偶数之和
```
