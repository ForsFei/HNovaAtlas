## 变量：给数据起名字

程序总要记住一些东西：一个价格、一个名字、计算到一半的结果。**变量**就是给这些数据起的名字。用一个等号把值"放进"变量：

```python filename="variables.py"
name = "小明"
age = 12
price = 3.5
```

读法：把 `"小明"` 存进变量 `name`。等号在这里是"赋值"，不是数学里的相等。赋值之后，任何地方写 `name` 就等于在使用 `"小明"`。

变量可以随时被重新赋值，新值会覆盖旧值：

```python filename="reassign.py"
count = 1
print(count)   # 输出 1
count = 2
print(count)   # 输出 2
count = count + 1
print(count)   # 输出 3
```

<Callout type="info" title="不用声明类型">

很多语言要求先声明"这个变量是整数"再使用，Python 不需要。你赋什么值，它就是什么类型——这让入门轻松很多。

</Callout>

## 三种基本类型

| 类型 | 名称 | 例子 | 用途 |
|------|------|------|------|
| `int` | 整数 | `42`、`-7`、`0` | 计数、数量 |
| `float` | 浮点数（小数） | `3.14`、`-0.5` | 价格、测量值 |
| `str` | 字符串（文字） | `"hello"`、`'你好'` | 名字、消息 |

还有一个特殊的 `bool`（布尔）类型，只有 `True` 和 `False` 两个值，后面讲条件判断时会大量用到。

用 `type()` 可以查看任何值的类型：

```python filename="types.py"
print(type(42))        # <class 'int'>
print(type(3.14))      # <class 'float'>
print(type("hello"))   # <class 'str'>
print(type(True))      # <class 'bool'>
```

<Callout type="warning" title="42 和 '42' 不是一回事">

`42` 是整数，能参与算术；`"42"` 是字符串，只是两个字符。初学者常在从键盘读取的输入上栽跟头——下一节会讲如何转换。

</Callout>

## 类型转换

类型之间可以互相转换：

```python filename="convert.py"
number = int("42")        # 字符串 -> 整数
pi = float("3.14")        # 字符串 -> 小数
text = str(100)           # 整数 -> 字符串
print(number + 8)         # 50
print(text + " 分")       # 100 分
```

注意 `int("3.14")` 会报错——字符串必须是合法的整数格式才能转成 int。

## 变量命名的规矩

好的名字让代码自己会说话。Python 变量命名规则：

- 只能用字母、数字和下划线，且不能以数字开头
- 区分大小写：`Age` 和 `age` 是两个变量
- 不能用 Python 的保留字（如 `if`、`for`、`print` 等）

社区惯例是**蛇形命名**（snake_case）：多个单词用下划线连接。

```python filename="naming.py"
student_name = "小明"    # 好：清楚
total_price = 19.9       # 好：清楚
a = 19.9                 # 差：a 是什么？
x1y2 = 3                 # 差：看不懂
```
