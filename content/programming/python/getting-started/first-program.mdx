## 程序是什么

一个程序就是一串指令：计算机从上到下逐行执行你写下的代码。先不着急理解原理，本篇的目标只有一个——亲手让一段代码跑起来。

## 先试试交互模式

打开命令行，输入 `python` 回车，你会看到 `>>>` 提示符。这就是**交互模式**（REPL）：你输入一行，它执行一行，立刻给你结果。

```python filename="命令行（REPL）"
>>> print("你好，世界")
你好，世界
>>> 2 + 3
5
```

注意两个细节：

- `print("...")` 让计算机把括号里的内容显示出来，输出不带引号。
- 直接输入 `2 + 3` 时结果自动显示；交互模式就像一台高级计算器。

输入 `exit()` 并回车即可退出交互模式。

## 写成文件再运行

交互模式适合试验，真正的程序要保存在文件里。创建你的第一个程序文件：

<Tabs label="查看两种建立文件的方式" defaultValue="vscode">
  <Tab value="vscode" label="用 VS Code">

1. 新建一个文件夹（例如 `python-learning`），在 VS Code 中打开它。
2. 新建文件，命名为 `hello.py`。
3. 输入下面两行代码并保存（`Ctrl + S`）。

  </Tab>
  <Tab value="manual" label="用记事本">

1. 打开记事本，输入下面两行代码。
2. 另存为 `hello.py`，保存类型选"所有文件"，编码选 UTF-8。
3. 记住保存的位置，比如桌面。

  </Tab>
</Tabs>

```python filename="hello.py"
# 我的第一行代码：向世界问好
print("你好，世界")
print("我正在学 Python")
```

以 `#` 开头的行是**注释**，写给人类看的说明，计算机直接跳过。好的注释是给自己（和以后的同事）留的笔记。

然后回到命令行，进入文件所在目录并运行：

```bash filename="命令行"
python hello.py
```

你会看到两行输出。恭喜——这是一个真正意义上的 Python 程序了。

## print 还能做什么

`print` 可以一次打印多个内容，用逗号隔开，中间会自动加空格：

```python filename="hello2.py"
print("姓名:", "小明")
print("1 + 2 =", 1 + 2)
```

输出：

```text
姓名: 小明
1 + 2 = 3
```

逗号后面如果是算式，Python 会先算出结果再打印——你已经能用它当计算器了。

<Callout type="danger" title="初学者最常见的两个报错">

1. **忘记引号**：`print(你好)` 会报 `SyntaxError`。文字内容要用引号包起来。
2. **中英文标点混用**：引号、括号必须用英文符号。中文引号 `""` 和英文引号 `" "` 看着像，计算机只认后者。报错时先检查标点。

</Callout>

<Accordion title="报错了怎么办？">

先读错误信息的**最后一行**，那是错误类型；再看它指出的**行号**，回到对应位置检查。语法错误（SyntaxError）多半是少了引号、括号或用了中文标点。把错误信息复制去搜索，也是完全正当的学习手段。

</Accordion>

## 动手试一试

1. 用交互模式计算 `365 * 24`，看看一年有多少小时。
2. 写一个 `about.py`，用两行 `print` 打印你的名字和今天想完成的事。
3. 故意把 `print` 写成 `pritn` 运行一次，观察错误信息，认识 NameError 长什么样。
