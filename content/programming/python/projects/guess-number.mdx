## 第一个完整程序

到目前为止你学的零件——变量、条件、循环、随机数——已经够拼出一个真正的游戏了。这个项目只有三十行左右，但它有完整的结构：随机目标、反复交互、判断输赢、结束收尾。

## 游戏规则

1. 程序随机选一个 1 到 100 之间的整数
2. 玩家反复输入猜测
3. 每次提示"大了"或"小了"
4. 猜中后公布用了几次

## 从骨架开始

先写能运行的最小版本，再逐步完善——**真实项目的正确开发顺序**：

```python filename="guess.py"
import random

answer = random.randint(1, 100)
guess = int(input("猜一个 1-100 的数字："))

if guess == answer:
    print("猜对了！")
else:
    print(f"错了，答案是 {answer}")
```

能跑，但只能猜一次。下一步让它循环起来。

## 加上循环与提示

```python filename="guess2.py"
import random

answer = random.randint(1, 100)
count = 0

while True:
    guess = int(input("猜一个 1-100 的数字："))
    count += 1

    if guess < answer:
        print("小了")
    elif guess > answer:
        print("大了")
    else:
        print(f"猜对了！你用了 {count} 次")
        break               # 猜中后跳出循环
```

`while True` 是"无限循环 + break 退出"的经典结构：不知道要循环几次，只知道"猜中才结束"。

## 处理非法输入

输入 `abc` 会怎样？`int("abc")` 抛 ValueError，程序崩溃。用学过的异常处理接住它：

```python filename="guess-final.py"
import random

answer = random.randint(1, 100)
count = 0

print("我想好了一个 1-100 的数字，猜猜看！")

while True:
    text = input("你的猜测：")

    try:
        guess = int(text)
    except ValueError:
        print("请输入一个整数")
        continue            # 这轮不算数，回到开头

    count += 1

    if guess < answer:
        print("小了，再猜")
    elif guess > answer:
        print("大了，再猜")
    else:
        print(f"猜对了！答案是 {answer}，你用了 {count} 次")
        break

    if count == 7:
        print("提示：二分法最多 7 次就能猜中 1-100 的任何数")
```

<Callout type="tip" title="对照检查你学过的每一课">

这个 30 行的程序里：`import` 来自模块一课；`while True / break / continue` 来自循环；`try / except` 来自异常处理；f-string 来自字符串；`+=` 来自运算符。**能独立读懂它，说明前面十二课都过关了。**

</Callout>
